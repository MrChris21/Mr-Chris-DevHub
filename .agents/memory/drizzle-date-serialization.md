# Drizzle Date Serialization

## The rule
Always call `serializeDates(row)` on any DB result before passing it to a Zod `.parse()` call in API route handlers.

**Why:** Drizzle's `pg` driver returns JavaScript `Date` objects for `timestamp` and `timestamptz` columns. Orval-generated Zod response schemas use `zod.string()` for datetime fields (the OpenAPI `format: date-time` maps to string in the generated schema), so parsing raw Drizzle rows throws a ZodError like `"Invalid input: expected string, received Date"`.

**How to apply:**
- The helper lives at `artifacts/api-server/src/lib/serialize.ts` — `serializeDates(value)` recursively converts any `Date` to `.toISOString()`.
- Use it in every route: `res.json(SomeResponseSchema.parse(serializeDates(row)))`.
- Also applies to arrays: `serializeDates(rows)` works fine on arrays.
- Does NOT affect non-date fields — safe to call unconditionally.
